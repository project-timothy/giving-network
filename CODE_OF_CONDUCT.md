# Code of conduct

This team is spread across churches, sending organizations, and time
zones, and not everyone here shares the same faith or none at all. The
code doesn't ask, and neither does this.

What we're asking instead: be plain, be kind, and argue about the work,
not the person. Iron sharpens iron, not people wearing each other down.

## What that looks like

- Assume good faith. Someone's rough PR or blunt comment is almost
  never an attack.
- Disagree openly, on the issue or the PR where the decision lives, not
  in a side channel. Say why, not just "this feels wrong."
- Review the code, not the contributor. "This function is doing too
  much" is feedback. "You always overcomplicate things" is not.
- If you don't know someone's situation, don't guess at it out loud.

## What isn't okay

Harassment, personal attacks, sustained disruption of an issue or
discussion, and sharing someone's private information without their
say-so. None of that has a place here, on any thread, in any repo under
this org.

## If something's wrong

Tell Derrick directly: floridayze@gmail.com. Most of the time this
starts as a private conversation, not a public one. If a pattern
continues after that conversation, losing access to the org is the next
step, not the first one.

This applies everywhere under the project-timothy org: issues, pull
requests, discussions, and anywhere else the work happens.
